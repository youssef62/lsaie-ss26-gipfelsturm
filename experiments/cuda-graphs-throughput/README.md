# CUDA Graph Throughput Experiment

This folder contains the scripts, Slurm logs, parsed results, and plots for the
Challenge 2 CUDA Graph experiments.

## Contents

- `code/launch.sh`: launcher used for the throughput jobs.
- `code/scripts/`: helper scripts for preflight checks, job submission, log parsing,
  result collection, and result summarization.
- `logs/`: Slurm batch scripts and raw job logs from the completed runs.
- `results/`: parsed CSV/Markdown summaries produced from the logs.
- `plots/`: generated visual summaries used for the report.
- `plot_cuda_graph_results.py`: local plotting script for regenerating the PNGs.

## Main Question

We tested whether CUDA Graph capture improves Megatron-LM training throughput by
reducing CPU-side kernel-launch overhead. The runs compare TransformerEngine
CUDA Graph scopes (`attn`, `mlp`, and default/full-layer) against no-graph
baselines, plus Megatron-local full-iteration graph capture.

## Key Files

- `results/challenge2_results.csv`: all parsed runs, including successful runs and
  OOM/failure cases.
- `results/challenge2_cuda_speedups.csv`: CUDA Graph runs matched against their
  baseline throughput.
- `results/challenge2_summary.md`: compact text summary generated by the parser.
- `plots/cuda_graph_speedups_by_model.png`: speedup/regression by model and graph
  scope.
- `plots/top_throughput_runs.png`: top throughput rows across the parsed runs.

## Regenerating

From this folder:

```bash
python3 plot_cuda_graph_results.py
```

To rebuild the CSV summaries from logs, copy `code/scripts/` and `code/launch.sh`
back to the repository root on Clariden, then run:

```bash
scripts/challenge2_collect_results.sh
```

The scripts expect the original repository layout, with `logs/` and `results/`
at the repository root.
